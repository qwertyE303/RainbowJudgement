# RainbowJudgement（彩虹判定）

> # ⚠️ 本项目代码由AI辅助完成！

## 判定

- **波长映射范围：380nm ~ 700nm**（深紫 → 红），tick 与判定文字按档位锚点线性渐变
- **判定限制**（PP 及以外保持原版判定不变）：
  - 可自定义（见实验性选项）
  - 默认设置：
    - 10° / 7.5ms
    - 15° / 12.5ms
    - 20° / 16.67ms
    - 30° / 25ms

## 统计与完美无瑕

- **平均判定**：
  - **颜色**：将每次判定按颜色对应的波长算数平均后映射的颜色
  - **平均绝对时间偏差**：对每次判定的时间误差绝对值求算术平均
  - **平均绝对角度偏差**：对每次判定的角度误差绝对值求算术平均
  - 支持在结尾页显示
  - 支持在关卡内实时显示，可编辑XY坐标、字体大小、计数间距
- **$X^n$完美无瑕**（基于原完美无瑕）：
  - **$X^n$颜色**：
    - 与自定义判定限制颜色/计数颜色一致
  - **n**： $n = \dfrac{1}{r} - 1$ ，其中 $r = \dfrac{1}{N}\sum_{i=1}^{N}\dfrac{|\theta_i|}{\theta_{PP}}$（ $\theta_i$ 为第 $i$ 次判定角度， $\theta_{PP}$ 为 PP 边界角度， $N$ 为判定次数）

## 自定义判定（实验性）

- **编辑自定义判定**：
  - 判定角度、最小限制时间与相应的计数颜色由玩家自定义
  - **自定义颜色**：
    - 玩家可选择使用波长对应的颜色或手动输入RGB值
- **显示判定计数**：
  - 由自定义判定决定，可编辑XY坐标、字体大小、计数间距
