# RainbowJudgement（彩虹判定）

> # ⚠️ 本项目代码由AI辅助完成！

## 判定

- **波长映射范围：380nm ~ 700nm**（深紫 → 红），tick 与判定文字按档位锚点线性渐变
- **判定限制**（PP 及以外保持原版判定不变）：
  - 紫：10° / 7.5ms
  - 靛：15° / 12.5ms
  - 蓝：20° / 16.67ms


## 统计与完美无瑕

- **平均判定**：
  - **颜色**：将每次判定按颜色对应的波长算数平均后映射的颜色
  - **平均绝对偏差**：对每次判定的时间误差绝对值求算术平均
- **$X^n$完美无瑕**（基于原完美无瑕）：
  - **$X^n$颜色**：
    - 与判定限制一致
  - **n**： $n = \dfrac{1}{r} - 1$ ，其中 $r = \dfrac{1}{N}\sum_{i=1}^{N}\dfrac{|\theta_i|}{\theta_{PP}}$（ $\theta_i$ 为第 $i$ 次判定角度， $\theta_{PP}$ 为 PP 边界角度， $N$ 为判定次数）
